# Python Calculator

My first Python programming project.

## Description

This is a beginner Python calculator that performs basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Invalid operator handling

## How to Run

Make sure Python is installed.

Open Command Prompt and navigate to the project folder:

```text
cd Desktop\python_calculator
## Run
python calculator.py
